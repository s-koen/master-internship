\begin{figure}[ht]

Let me investigate.

was related to the binary abundance post-processing.

while this \emph{obviously} should be \(\Delta M_\text{acc} = M_\text{acc, f} - M_\text{acc, i}\).

\section{Mean Molecular weight MESA vs Monash}

We saw that there is a difference between the mean molecular weight of the MESA
models and the initial mean molecular weight of the Monash models.

I want to understand where these differences come from.

Let me start by computing \(\mu \) from the \citet{asplund2009} solar abundances for the \emph{MESA} initial
Helium mass-fraction.

Then I will modify my \citet{asplund2009} abundances to the ``canonical'' helium mass-fraction as explained
in \citet{karakas2014}.

		the single star model in terms of enrichment.

It took me some time to find the cause, but I the plot below shows the problem.

\begin{figure}[ht]
	\marginfignote{0}{The binary models start with the wrong thermal pulse count.
		They are offset by exactly 1, which makes sense since the MESA TPAGB routine
		starts a binary with TP 1, not 0.
		If I then add the MESA count to the single star
		count at the starting time of the binary, we get a mismatch.
	}
	\marginfignote{10}{Towards the end of the evolution, this mismatch does not
		significantly affect envelope abundances anymore.
		Therefore, the accreted abundances will also not be affected much.
		However, when dredge up
		is just starting we can get quite large differences.
		Luckily the fix is quite easy.
	}
	\centering
	\incplot{w-30-show-wrong-2}
\end{figure}

\begin{minted}[fontsize=\small,breaklines]{py}
from:
    self.tp_count[self.simple_end_idx :] = self.model.TP_count[::sampling] + simple.TP_count[self.simple_end_idx]
to:
    self.tp_count[self.simple_end_idx :] = self.model.TP_count[::sampling] -self.model.TP_count[0]  + simple.TP_count[self.simple_end_idx]
\end{minted}
