\section{Analytic}\label{sec:1}
I am basing my implementation on the results from \citet{soberman1997}.

The code below shows my implementation.
\begin{minted}[fontsize=\small]{py}
class CombineEvolve:
    def __init__(self, alpha, beta, delta, gamma, qs, A=1, M_1_i=2):
        self.alpha = alpha  # fraction lost from donor as wind
        self.beta = beta  # fraction lost from accretor as wind
        self.delta = delta  # fraction transferred to CCT
        self.gamma = gamma  # measure for CCT distance
        self.epsilon = 1 - self.alpha - self.beta - self.delta
        self.qs = 1 / qs # note that soberman1997 uses q = m_d / m_a
        self.q0 = 1 / qs[0]

        self.A = A  # enhancement factor
        self.M_1_i = M_1_i  # initial mass of donor

        self.curA = self._comp_curA()
        self.curB = self._comp_curB()
        self.curC = self._comp_curC()

    def _comp_curA(self):
        # equation B8 soberman1997
        return self.A * self.alpha + self.gamma * self.delta

    def _comp_curB(self):
        # equation B9 soberman1997
        return (self.A * self.alpha + self.beta) / (1 - self.epsilon)

    def _comp_curC(self):
        # equation B10 soberman1997
        term_1 = (self.gamma * self.delta * (1 - self.epsilon)) / self.epsilon
        term_2 = (self.A * self.alpha * self.epsilon) / (1 - self.epsilon)
        term_3 = (self.beta) / (self.epsilon * (1 - self.epsilon))
        return term_1 + term_2 + term_3

    @property
    def a_over_a0(self):
        # table 5 soberman1997
        term_1 = (self.qs / self.q0) ** (2 * self.curA - 2)
        term_2 = ((1 + self.qs) / (1 + self.q0)) ** (1 - 2 * self.curB)
        term_3 = ((1 + self.epsilon * self.qs) / (1 + self.epsilon * self.q0)) ** (
            2 * self.curC + 3
        )
        return term_1 * term_2 * term_3

    @property
    def M_tot_over_M_tot0(self):
        # table 5 soberman1997
        term_1 = (1 + self.qs) / (1 + self.q0)
        term_2 = ((1 + self.epsilon * self.qs) / (1 + self.epsilon * self.q0)) ** (-1)
        return term_1 * term_2

    @property
    def P_over_P0(self):
        # table 5 soberman1997
        term_1 = (self.qs / self.q0) ** (3 * self.curA - 3)
        term_2 = ((1 + self.qs) / (1 + self.q0)) ** (1 - 3 * self.curB)
        term_3 = ((1 + self.epsilon * self.qs) / (1 + self.epsilon * self.q0)) ** (
            3 * self.curC + 5
        )
        return term_1 * term_2 * term_3

    @property
    def M_tot(self):
        return self.M_1_i * (1 + 1 / self.q0) * self.M_tot_over_M_tot0

    @property
    def M_d(self):
        return self.M_tot / (1 + 1 / self.qs)

    @property
    def M_a(self):
        return 1 / self.qs * self.M_d


\end{minted}

\newsubsection{Exploring Effects of a Circumbinary Corotating Toroid}

We have seen that winds and isotropic re-emission can have important effects on the properties of the binary orbits. \citet{soberman1997} however, describe another mechanisms that, according to their paper, can be very important for angular momentum loss from an orbit. This is the Circumbinary Corotating Toroid or CCT. It is described by two parameters, \(\delta \) and \(\gamma \). The efficiency of mass transport to the CCT is described by \(\beta \). It is the analogue to \(\alpha \) and \(\beta \) for winds and inefficient accretion. The second parameter, \(\gamma \) is a parameter that encodes the specific angular momentum of the ejected material and the specific angular momentum of the binary. In the case of the CCT, this is closely related to the ratio of the CCT and the binary such that as a good first approximation, one can take \(\gamma = \sqrt{a_\text{ring} / a_\text{bin}} \). The difficultly then is in taking a realistic value for \(a_\text{ring}\). \citet{soberman1997} propose a modest value of \(2.25 a_\text{bin}\), which corresponds to \(\gamma = 1.5\).

With these values, we find the following effects on the orbit for varying strengths of \(\delta \) and a constant \(\gamma = 1.5\):
